# Messy Python Code Improvement

## About

This project demonstrates how Python code can be improved by making it cleaner, easier to read, and easier to maintain.

## Improvements

* Used meaningful function and variable names.
* Divided the program into smaller functions.
* Added docstrings to explain each function.
* Handled empty lists safely.
* Used Python list comprehension to find even numbers.
* Added a `main()` function to organize program execution.

## Technologies Used

* Python 3

## How to Run

Run the following command in the project folder:

```bash
python main.py
```

## Example Output

```text
Numbers: [10, 15, 20, 25, 30]
Average: 20.0
Even numbers: [10, 20, 30]
```
